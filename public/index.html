API Documentation

Create Session

POST /api/session/create
Headers: x-api-key: YOUR_API_KEY

Response: { sessionId, qrCodeUrl }

Download Credentials

GET /api/downloadCreds/:sessionId

Returns the creds.json file for the bot

List Sessions

GET /api/sessions
Headers: x-api-key: YOUR_API_KEY

Returns all sessions for your account

Delete Session

DELETE /api/session/:sessionId
Headers: x-api-key: YOUR_API_KEY

Removes a session permanently

# CHARLTON-MD WhatsApp Bot

A WhatsApp bot built with Baileys and Node.js

## Quick Start

```bash
npm install
npm start
```

## Environment Variables

Create a `.env` file with:
```
OWNER_NUMBER=254712345678
OWNER_NAME=Charlton
PREFIX=.
BOT_MODE=public
```

## Features

- 🔧 Command Handler
- 🤖 Auto-replies
- 📝 Message Logging
- 🐳 Docker Support

## Deployment

- Heroku
